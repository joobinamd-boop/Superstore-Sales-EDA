## Superstore Exploritory Data Analysis

## Overview
This project performs Exploritory Data Analysis (EDA) on a superstore sales dataset using Python. The goal is to understand sales and profit patterns 
across products, categories, regions, customer segment, and time.

## Tools &Libraries
Python
Pandas
NumPy
Matplotlib
Seaborn

## EDA Performed
Data overview and cleaning
Missing values and duplicate analysis
Numeerical and categorical analysis
Date/time analysis
Correlation analysis
Sales and profit analysis
Category region, customer, and product analysis
